# 결제 연동

VIBEBASE는 Creem 결제 시스템을 통해 구독 및 일회성 결제를 지원합니다.

## 결제 유형

### 구독 결제 (Recurring)

월간 또는 연간 구독 플랜을 제공합니다.

- 자동 갱신
- 구독 취소/재개
- 고객 포털 제공

### 일회성 결제 (One-time)

단일 결제로 제품 또는 서비스를 구매합니다.

- 환불 처리 지원
- 구매 내역 관리

## 결제 플로우

```
사용자 → 가격 페이지 → Creem Checkout → 결제 완료 → Webhook 처리 → DB 업데이트
```

## 웹훅 이벤트

다음 이벤트들이 자동으로 처리됩니다:

| 이벤트 | 설명 |
|-------|------|
| `checkout.completed` | 결제 완료 |
| `subscription.created` | 구독 생성 |
| `subscription.updated` | 구독 상태 변경 |
| `subscription.cancelled` | 구독 취소 |
| `subscription.renewed` | 구독 갱신 |
| `payment.failed` | 결제 실패 |

## 가격 플랜 관리

관리자 대시보드(`/admin/pricing`)에서 가격 플랜을 관리할 수 있습니다:

- 플랜 생성/수정/삭제
- Creem 제품 ID 연동
- 기능 목록 설정
- 활성/비활성 상태 관리

## 고객 포털

사용자는 `/portal`을 통해 Creem 고객 포털에 접근하여 구독을 직접 관리할 수 있습니다.
