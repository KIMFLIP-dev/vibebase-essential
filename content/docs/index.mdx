# VIBEBASE

**VIBEBASE**는 스타트업이 빠르게 SaaS 애플리케이션을 구축할 수 있도록 설계된 Next.js 스타터킷입니다.

## 주요 기능

- **Supabase 인증** - 이메일/비밀번호, 소셜 로그인 지원
- **Creem 결제 연동** - 구독 및 일회성 결제 처리
- **역할 기반 권한** - user, admin, super_admin 역할 시스템
- **관리자 대시보드** - 사용자, 구독, 설정 관리
- **반응형 UI** - Tailwind CSS + shadcn/ui 컴포넌트

## 기술 스택

| 카테고리 | 기술 |
|---------|------|
| 프레임워크 | Next.js 15 (App Router) |
| 데이터베이스 | Supabase (PostgreSQL) |
| 인증 | Supabase Auth |
| 결제 | Creem |
| 스타일링 | Tailwind CSS |
| UI 컴포넌트 | shadcn/ui |
