# 시작하기

VIBEBASE를 사용하기 위한 환경 설정 및 프로젝트 시작 방법을 안내합니다.

## 환경 요구사항

시작하기 전에 다음 도구들이 설치되어 있어야 합니다:

- **Node.js** 18.0 이상
- **npm** 또는 **pnpm**
- **Git**

## 프로젝트 클론

```bash
git clone https://github.com/your-username/vibebase-creem-app.git
cd vibebase-creem-app
```

## 의존성 설치

```bash
npm install
```

## 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)에 접속하여 확인할 수 있습니다.

## 다음 단계

환경 설정이 완료되면 [설치 가이드](/docs/installation)를 따라 Supabase와 환경 변수를 설정하세요.
